Super Admin Login

இந்தப் பக்கம் அனுமதி பெற்ற நிர்வாகிக்காக மட்டுமே. புதிய Admin பதிவு இங்கே கிடையாது. Login + Authenticator MFA இரண்டும் கட்டாயம்.

Authenticator Verification

உங்கள் Authenticator App-ல் வரும் 6 இலக்கக் குறியீட்டை உள்ளிடவும்.

MFA அமைக்கவும்

Google Authenticator அல்லது Microsoft Authenticator மூலம் கீழே உள்ள QR-ஐ scan செய்யவும். Scan செய்ய முடியாவிட்டால் Secret Key-ஐ கைமுறையாகச் சேர்க்கவும்.

இந்த Login பக்கத்தில் Public Registration இல்லை. Super Admin உரிமை Database-ல் தனியாக அனுமதிக்கப்பட்ட கணக்கிற்கு மட்டுமே வழங்கப்படும்.
