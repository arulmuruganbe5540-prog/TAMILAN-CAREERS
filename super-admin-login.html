Super Admin Login

இப்போது Email + Password மூலம் மட்டும் Login செய்யலாம். Authenticator MFA இந்தப் பக்கத்தில் பயன்படுத்தப்படாது. Super Admin அனுமதி Database-ல் வழங்கப்பட்ட கணக்கிற்கு மட்டுமே Dashboard அணுகல் கிடைக்கும்.

புதிய கணக்கு பதிவு

பதிவு செய்த Email-க்கு உறுதிப்படுத்தல் இணைப்பு அனுப்பப்படும். பதிவு செய்தாலே Super Admin அனுமதி கிடைக்காது.

புதிய Password அமைக்கவும்
