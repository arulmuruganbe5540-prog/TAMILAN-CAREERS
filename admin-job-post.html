📢 Super Admin – அனைத்து வேலைகளையும் சேர்க்கவும்

அரசு, தனியார், வெளிநாட்டு வேலைகளை நேரடியாகச் சேர்த்து Draft / Review / Approved / Publish முறையில் நிர்வகிக்கலாம்.

பாதுகாப்பு: Draft / Review / Approve ஆகிய நிலைகளுக்குப் பிறகு தனி Publish செயல் உள்ளது. Publish செய்யும்போது Database Function Super Admin அனுமதி, Approved நிலை, சரிபார்க்கப்பட்ட நிறுவனம் ஆகியவற்றை மீண்டும் சரிபார்க்கும். வெளியிடப்பட்ட வேலை public.jobs அட்டவணையில் சேரும்.

✍️ புதிய வேலை அறிவிப்பு உருவாக்கவும்

Super Admin மூன்று பிரிவுகளிலும் நேரடியாக வேலை சேர்க்கலாம்.
மத்திய அரசு அல்லது தமிழ்நாடு அரசு — இதில் ஒன்றைத் தேர்ந்தெடுக்கவும்.
Super Admin நேரடியாகச் சேர்க்கும்போது விருப்பத்தேர்வு. Company submission என்றால் Verified நிறுவனம் கட்டாயம்.
அரசு, தனியார், வெளிநாட்டு — எல்லா வேலைகளுக்கும் சரியான நாட்டைத் தேர்ந்தெடுக்கவும். Dubai வேலைகளுக்கு United Arab Emirates தேர்வு செய்யவும்.
ஒரே வேலைக்கு பல கல்வித் தகுதிகளைத் தேர்வு செய்யலாம்.
