Important Security Notes

  • Public frontend code must contain only the Supabase publishable key. Never place service_role or secret keys in HTML or JavaScript.
  • Super Admin role checks and database Row Level Security must both remain enabled.
  • Public self-registration must never grant the Super Admin role.
  • Repository visibility is currently Public, so the HTML source code can be viewed on GitHub even though database records are protected by RLS. Changing visibility may affect GitHub Pages hosting.
  • Supabase leaked-password protection is currently disabled and must be enabled in the Supabase Auth settings.
  • Some privileged review, company-verification and job-publication RPCs still require a verified authenticator factor even though the login page currently uses Email and Password only.
