Secure Facebook connection — setup required

Do not paste a Facebook password or Page Access Token into this page, a chat, or website JavaScript. Store credentials only as Supabase Edge Function secrets.

1
Create or open a Meta Developer App

Use the Meta account that has the Page task CREATE_CONTENT (or full Page management). Add the Facebook Login product if you use the OAuth connection flow.

Open Meta for Developers ↗
2
Get the Page ID and Page Access Token

Grant the Page publishing permissions: pages_manage_posts, pages_read_engagement, and pages_show_list. Select the Page named TAMILAN CAREERS OFFICIAL and obtain its Page ID and Page Access Token.

Open Graph API Explorer ↗
3
Add two secrets in Supabase

Supabase Dashboard → Project Settings / Edge Functions → Secrets. Add these exact names:

FACEBOOK_PAGE_ID
FACEBOOK_PAGE_ACCESS_TOKEN

Never put either value in public HTML, GitHub, or the browser.

Open Supabase Function Secrets ↗
4
Verify connection and enable publishing

Return here and tap Refresh status. When both server secrets are detected, turn Auto Publish ON. A real Facebook test post should be made only after you confirm the connection and approve a test job.

Publishing queue

A job is queued only when its status changes to Published. Each job can enter the queue once, preventing duplicate posts. If a request has an uncertain result, check the Facebook Page before retrying.
